## Формат rsf

Файл `.rsf` представляет собой **ZIP-архив**, содержащий XML-таблицы, настройки и служебные данные Ramus. Модель хранится не в одном дереве `<diagram>`, а в связанных записях с идентификаторами элементов и атрибутов.

### Основные XML-файлы

| Файл относительно `data/` | Содержимое | Назначение |
|---|---|---|
| `elements.xml` | `ELEMENT_ID`, `QUALIFIER_ID`, признаки создания и удаления | реестр элементов |
| `qualifiers.xml` | типы элементов | отличать блоки, потоки, сектора и узлы дерева |
| `attributes.xml` | идентификаторы и типы атрибутов | интерпретация записей |
| `Core/attribute_texts.xml` | текстовые значения | имена блоков и стрелок |
| `Core/attribute_other_elements.xml` | ссылки между элементами | связи сектор–поток и сектор–функция |
| `Core/attribute_hierarchicals.xml` | иерархические отношения | исследование дерева модели |
| `Core/attribute_longs.xml` | целочисленные атрибуты | служебные ссылки |
| `IDEF0/attribute_rectangles.xml` | `X`, `Y`, `WIDTH`, `HEIGHT` | геометрия блоков |
| `IDEF0/attribute_sectors.xml` | данные участков стрелок | составные стрелки |
| `IDEF0/attribute_sector_points.xml` | координаты точек участков | геометрия линий |
| `IDEF0/attribute_sector_borders.xml` | границы и подключения участков | роли стрелок, соединения, туннели |
| `IDEF0/attribute_sector_properties.xml` | отображение подписей | подписи и тильды |
| `IDEF0/attribute_decomposition_types.xml` | тип декомпозиции | проверка декомпозиции |
| `IDEF0/attribute_function_types.xml` | тип функции | свойства блоков |
| `IDEF0/attribute_function_ouners.xml` | владельцы функций | требует дальнейшего исследования |
| `IDEF0/attribute_model_preferences.xml` | автор, название, даты, параметры | метаданные |

Файлы `user/*`, `data/Chart/*`, `data/Eval/*`, истории изменений, шрифты и цвета пока не входят в минимальный набор данных валидатора. `data/streams.xml` относится к внутренним потокам контейнера, **не** к IDEF0-стрелкам.
